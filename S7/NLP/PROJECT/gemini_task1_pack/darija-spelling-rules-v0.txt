Project 16: Darija spelling rules v0
Author: Abdellah Elkhalil Kessoum. Status: draft v0, to be agreed by the team. Public sources only. No personal data.
These rules give one written form to each Darija word, so that annotators, the glossary and the data pipeline all spell it the same way. They apply to Arabic script and to Arabizi.
Rules
The q sound. Write ق for every q or g sound, whatever the speaker's accent. Many Algerians pronounce it "g", but one letter keeps the spelling identical across regions and works with standard Arabic tools. The Arabizi letter is q.
Vowels. Write long vowels with ا و ي. Do not write short vowels and do not use diacritics.
Arabizi. Use one system for everyone: 3 = ع, 7 = ح, 2 = hamza when needed, kh = خ, gh = غ, ch = ش, dj = ج, q = ق. Vowels are a, e, i, o and ou, where ou stands for /u/. Latin spellings of drug names stay conventional.
Negation. Attach the final ش to the verb: ما نعرفش (ma n3arfch). Write ما as a separate word.
One spelling per word. If a word has two common spellings, the table below fixes the one we use. Other spellings go in the glossary as variants.
